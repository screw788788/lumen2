# Lumen Camera - Pro Camera App

Lumen Camera is a streamlined, high-performance pro camera application designed for crisp photo capture with full control parameters (Exposure, Manual Focus, Depth Control, D-Log, RAW mode simulation, Exposure Lock, and Multi-Sensor Resolution Profiles up to 200MP).

## GitHub Actions Automated APK Build

This repository is pre-configured with GitHub Actions to build an APK directly from GitHub without requiring a local Android Studio setup.

### Quick Setup Steps:
1. Push this repository to GitHub on the `main` branch.
2. Navigate to the **Actions** tab on your GitHub repository.
3. Select **Build Android APK**.
4. Once completed, download the `LumenCamera-APK` artifact from the run summary.
